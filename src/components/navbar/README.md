# Navigation Bar

## Image

![NavBar-component](/doc/NavBar-component.png)

## Description

The `Navigation Bar` component builds the main site navigation. It includes the home link, a desktop list of menu entries, and a mobile menu triggered by a hamburger button. The component reads its items from the translation configuration and renders links using Vue Router.
